# The_World_of_Brium

Website for Author: Jeremy Cole

Home - A page showing the main cover of the current work and its blurb, followed by store information. The next section down would have information about me and my objectives with this universe. Lastly, newsletter signup with a call to action, with different selections for a blog subscription and book release information. This ought to mention a free short story to go with the newsletter that's connected with the main work. There could also be advertising for a fan Discord server or a Youtube page that I might make for an audiobook series, but I have to see if those are feasible.
Books -  A more detailed page about my series, then each work within each series. For launch, it will just be this work, plus an extra page regarding future plans as a tease. This will have a rough summary of what happens, a basic description of the race featured, then the main characters and locations of the work. This section will be heavy on the art if I can get good assets.
About - Split into two sections, Author and World. Author would detail my background and mission, while World would detail some inspirations and what I wish to see happen with it.
News - This would have the contents of my book development newsletters for ease of access, along with a call to join with an email and receive a free story.
Blog - This would have the blog newsletters in a condensed location and a call to join it as well. This and the news page will have one image each, with supplemental images on what I see fit for the news.
Sign-Up - Invitations to join either newsletter and advertising for their perks and benefits. 
Store - Would lead to the sub-domain for the store page itself, which I plan on making myself.
Contact - A website email, social media links and maybe even a Discord server invite for fans of the work. The Discord server could also be advertised on the main page, but might need to be added later when the book actually launches.

Dark Blue or Green color palette
